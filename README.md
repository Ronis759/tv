# IPTV ТВ (Android TV / ТВ-бокс)

Нативное приложение: Kotlin + Media3 ExoPlayer. Играет http/https, HLS и MPEG-TS без ограничений CORS.

## Как получить APK
1. Создайте репозиторий на GitHub и загрузите в него содержимое этой папки (включая скрытую папку `.github`).
2. Откройте вкладку **Actions** → **Build APK** → **Run workflow** (запускается и автоматически при push).
3. Через 3–6 минут откройте выполненный запуск → раздел **Artifacts** → скачайте `iptv-tv-apk` (внутри `app-debug.apk`).
4. Перенесите APK на бокс (флешка, ADB, либо приложение Downloader) и установите. Разрешите установку из неизвестных источников.

## Управление
- **OK** — список каналов (слева — группы, первый пункт «Настройки»)
- **←** — архив (слева — дни, справа — передачи), **→** в архиве — перемотка на 30 с
- **↑/↓**, CH+/CH− — переключение каналов, **Назад** — закрыть панель
- **Меню / Info** — настройки / информация о канале

Чтобы не вводить ссылку с пульта, впишите её в `app/src/main/res/values/strings.xml` (`default_playlist`, `default_epg`).
