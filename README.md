# Noxis IPTV (Android TV / ТВ-бокс)

Нативное приложение: Kotlin + Media3 ExoPlayer. Играет http/https, HLS и MPEG-TS без ограничений CORS, а также udp:// (multicast) и rtsp://.

## Как получить APK
1. Создайте репозиторий на GitHub и загрузите в него содержимое этой папки (включая скрытую папку `.github`).
2. Откройте вкладку **Actions** → **Build APK** → **Run workflow** (запускается и автоматически при push).
3. Через 3–6 минут откройте выполненный запуск → раздел **Artifacts** → скачайте `iptv-tv-apk` (внутри `app-debug.apk`).
4. Перенесите APK на бокс (флешка, ADB, либо приложение Downloader) и установите. Разрешите установку из неизвестных источников.

## Управление
- **OK** — список каналов (слева — группы, первый пункт «Настройки»)
- **←** — архив (слева — дни, справа — передачи). Также: **OK** → колонка значков слева → **↺ Архив**, или удержание OK на канале → **↺ Архив канала**
- Во время архива **←/→** — перемотка на 30 с (удержание — непрерывная, с ускорением), с панелью перемотки, **Назад** — вернуться в прямой эфир
- Если архив не открылся, приложение само пробует другие форматы ссылки (в т. ч. Flussonic) и запоминает рабочий для сервера
- **↑/↓**, CH+/CH− — переключение каналов, **Назад** — закрыть панель
- **Меню / Info** — настройки / информация о канале

## Избранное и группы
- **Удерживайте OK на канале** в списке — добавить в избранное / убрать (запасные клавиши: Меню, «*», жёлтая). В списке избранные отмечены ★, сам список — группа **★ Избранное**.
- **Красная кнопка или «*»** при просмотре — добавить / убрать текущий канал из избранного.
- **Удерживайте OK на группе** — скрыть её. Вернуть или скрыть несколько групп сразу: пункт **☰ Группы…** (OK — показать / скрыть, «Назад» — вернуться к списку).
- Скрытые группы не показываются в списке и в «Все», а ↑/↓ их пропускают. Каналы в избранном видны всегда.
- ↑/↓ листают каналы той группы, которую вы выбрали в списке (например, только избранное).
- Избранное и скрытые группы запоминаются по названию и общие для всех плейлистов.
- На панели с названием канала слева показывается его значок.

Чтобы не вводить ссылку с пульта, впишите её в `app/src/main/res/values/strings.xml` (`default_playlist`, `default_epg`).

## Обновление приложения
APK подписывается постоянным ключом `app/debug.keystore`, а `versionCode` растёт с каждым запуском сборки, поэтому новые версии ставятся **поверх** установленной с сохранением настроек.
Если у вас стоит версия, собранная до появления этого ключа, один раз удалите её перед установкой новой (подписи у них разные).
Ключ лежит в репозитории открыто и нужен только для личной отладочной сборки; для публикации заведите собственный.

## Устойчивость воспроизведения
- Обрыв связи, закрытие потока сервером или «зависание» буферизации дольше 20 с — автоматическое переподключение (до 5 попыток с нарастающей паузой). Переключение канала отменяет повторы.
- User-Agent, с которым сервер ответил на запрос плейлиста, запоминается и используется плеером для потоков (если не задан вручную в настройках).
- Кэш плейлиста хранится отдельно для каждой ссылки; если сервер недоступен, показывается сохранённый список с пометкой.
- Программа передач скачивается в файл и разбирается потоково; в памяти остаются только передачи каналов из плейлиста и только за нужное число дней архива.

## Серверы
Приложение по умолчанию запускается без плейлиста. Адрес вводится в настройках либо через **«Ввести секретный код»**: адреса, привязанные к кодам, хранятся в приложении только в зашифрованном виде (`Secrets.kt`). Плейлист или список серверов можно загрузить из файла в настройках.

## Автообновление из GitHub
1. Впишите репозиторий в `app/src/main/res/values/strings.xml` → `github_repo` (формат `владелец/имя`, репозиторий должен быть публичным). Пусто — обновления отключены.
2. Каждый push собирает APK и публикует **Release** `v<номер запуска>` с файлом `app-debug.apk` (номер = `versionCode`).
3. Приложение при запуске (не чаще раза в 6 часов) и по кнопке **Проверить обновления** в настройках сравнивает свой `versionCode` с номером последнего релиза и предлагает скачать и установить новую версию.
4. При первой установке Android попросит разрешить «установку из неизвестных источников» для этого приложения; само подтверждение установки система показывает всегда.
